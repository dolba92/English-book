Вот объединённый, структурированный промпт, который можно дать ChatGPT, Claude, Gemini или другому ИИ для генерации проекта.

# Промпт

Ты — Senior Full-Stack разработчик с опытом создания современных веб-приложений для изучения языков. Твоя задача — создать полноценный сайт для изучения английского языка через чтение книг.

Проект должен быть полностью готов к запуску без бэкенда и работать полностью в браузере.

## Общие требования

Создай полноценное приложение с современным кодом.

Используй:

* HTML5
* CSS3
* JavaScript (желательно React, но можно и Vanilla JS)
* Вся логика должна работать на стороне клиента.
* Код должен быть чистым, структурированным и хорошо разделён на компоненты.
* Не использовать серверную часть.

Результат должен быть готовым проектом:

* index.html
* style.css
* script.js (или React-проект со всеми файлами)

# Главная страница

На главной странице отображаются карточки книг.

Каждая карточка содержит:

* обложку книги
* название
* автора
* уровень английского (A1, A2, B1, B2, C1)
* процент прочтения
* кнопку "Читать"

Если книга уже читалась — отображается прогресс.

Например:

72% прочитано

---

# Загрузка книг

Пользователь может загрузить:

* EPUB
* FB2

Необходимо распарсить книгу полностью.

Использовать библиотеки:

* epub.js
* FB2 parser (или собственный простой парсер)

После загрузки автоматически:

* определяется содержание
* главы
* текст
* обложка (если есть)
* автор
* название

Если у книги нет обложки — создать красивую обложку автоматически.

---

# Читалка

Это основная часть приложения.

Не использовать бесконечную вертикальную прокрутку.

Вместо этого сделать страницы.

То есть книга читается как настоящая электронная книга.

Переход между страницами:

← предыдущая

→ следующая

На одной странице отображается несколько абзацев.

После нажатия происходит плавное перелистывание.

# Главы

Каждая глава должна:

* начинаться с новой страницы
* иметь красивый заголовок
* располагаться по центру
* быть жирной
* использовать другой декоративный шрифт
* визуально отделяться от текста

Между предложениями не должно быть огромных отступов.

Текст должен выглядеть как в современной электронной книге.

# Перевод слов

При наведении мыши на любое слово появляется красивый tooltip.

В tooltip отображаются:

* перевод
* несколько значений слова
* часть речи
* транскрипция
* кнопка прослушивания
* кнопка "Добавить в словарь"

Например:

run

[rʌn]

глагол

• бежать

• работать

• запускать

🔊 Прослушать

➕ Добавить

# Раздел "Изучение"

Добавить несколько видов тренировок слов.

Минимум:

## 1. Flashcards

Показывается английское слово.

По клику открывается перевод.

---

## 2. Выбери правильный перевод

Тест с вариантами ответов.

---

## 3. Собери слово

Буквы перемешаны.

---

## 4. Напиши перевод

Пользователь вводит перевод самостоятельно.

---

## 5. Напиши слово на английском

Показывается русский перевод.

Нужно написать английское слово.

---

## 6. Правда или ложь

Показывается слово и перевод.

Нужно определить, правильно ли они соответствуют друг другу.

---

## 7. Повторение сложных слов

Система показывает слова, в которых пользователь чаще ошибался.
